# 🎵 Music Player using JavaScript

A modern and responsive **Music Player Web Application** developed using **HTML**, **CSS**, and **JavaScript**.  
This project provides a complete music player experience with audio controls, song details, playlist support, and smooth UI interactions.

---

## 🚀 Features

### 🎧 Audio Controls
- ▶️ Play Song
- ⏸️ Pause Song
- ⏭️ Next Track
- ⏮️ Previous Track

### 📄 Song Information
- 🎵 Song Title Display
- 👨‍🎤 Artist Name Display
- ⏱️ Song Duration Display

### 🎚️ Player Functionalities
- 📊 Interactive Progress Bar
- 🔊 Volume Control
- ⚡ Real-Time Audio Updates
- 📱 Responsive User Interface

### ⭐ Bonus Features
- 🎶 Playlist Support
- 🔁 Autoplay Next Song
- 🎨 Smooth Hover Effects & Animations

---

## 🛠️ Technologies Used

- **HTML5** → Structure of the music player
- **CSS3** → Styling, animations, and responsive layout
- **JavaScript (ES6)** → Audio handling and interactive functionality
